# Go SFU + C++ SDK：模拟测试验收

更新：2026-10-28。**按用户最新要求，以模拟测试作为本轮验收依据，不要求真机实测。** 不再用没有 ARM64 板卡、手机、摄像头、麦克风、扬声器或硬件温度／功耗数据阻止功能通过。仍遵守无桌面操作的仓库约定。

## 当前结论

全部 34 项按模拟证据分为：**5 项通过、14 项部分通过待补模拟、7 项未通过、8 项尚未模拟。** “部分通过”是覆盖情况，正式状态仍为“未测”，但已明确列出通过的子项，避免和“完全没有测试”混淆。

5 项通过：V-02 多用户独立观看、V-08 聚合订阅控制、B-03 多回放会话的独立流转发、B-04 同回放源多人分发、N-05 节点重启与媒体重建。回放会话由不同内容的独立合成流模拟；录像读取和 seek 属于外部源模块，SFU 的独立流转发据实际解码和生命周期断言判定。B-01 文件源接入仍单独待补。

用户改变的是验收环境，不是删除软件功能或性能指标。因此没有模拟过的弱网、FEC、软件混音／AEC、文件源、P95、容量和 8 h，不能仅凭已有基础场景改为通过。它们都可以用软件模拟；下表不再要求真机作为补测前提。

## 证据与判定

- 使用上一轮真实执行的 [15 个媒体／传输模拟场景](../../out/uav-sfu-go/20261028-strict-transport/report.md)、[6 个 UDP/TCP 恢复场景](../../out/uav-20261028-strict-recovery.json)及 540 个 Go 测试／子测试记录。**此次是按新口径复核已有证据，不是重新执行了媒体测试。**
- [新模拟验收报告](../../out/uav-sfu-go/20261028-simulation-acceptance/report.md) 和 [机器可读结果](../../out/uav-sfu-go/20261028-simulation-acceptance/result.json) 与历史测量分开保存，没有覆盖原始失败或测量。
- 恢复证据核对服务端与客户端 SHA256、实际 selected candidate pairs、恢复后实际帧数、新 SID、源标识、旧 handle 拒绝及撤轨不复活。只有退出码为 0 不足以得到 N-05 通过。
- 每项通过必须具有对应的 PASS 断言，并满足要求的编码／协议组合；重复轮次里出现失败不能被一次成功覆盖。源码缺口优先于场景成功。
- 本轮新增 7 个模拟判定测试，加原有 11 个报告判定测试，**18/18 通过**。未新增或改动原生媒体实现，因此没有重复运行已通过的媒体构建和测试。
- B-07 本轮 TCP 模拟通过，但历史间歇连接失败尚未定位并关闭，继续保留为未通过；该状态与是否有真机无关。
