# 应用完善与中文界面

目标：完善视频会议、传屏、远程控制和播放器，使用中文界面。目标仍在进行；本文件记录实际增量及未完成范围，不把中文化或单轮测试等同于四个产品全部完善。

## 当前优先级与功能增量（2026-10-27）

用户要求先实现功能，性能和传输问题留到后续处理，并且不做过多验证。后续只执行与本次功能直接相关的必要编译和基本检查，不扩展性能、传输或长时间回归；整体应用完善仍有后续范围。

播放器新增外挂字幕：UTF-8 SRT / WebVTT 文件选择、路径加载与拖放；中文、多行和重叠字幕；显示开关与 `V` 快捷键；前后 10 分钟的毫秒偏移、重置与移除。字幕跟随播放位置，暂停和拖动进度后更新，更换媒体时清除；字幕加载失败保留旧字幕，不中断播放。界面和失败提示使用中文。暂不含内嵌字幕、ASS/SSA、样式与定位渲染或其他文本编码。

验证：播放器 Release 构建、CTest 5/5 通过（解析/时序/文件加载、媒体 fixture、播放输出、空窗口、UI 集成），包括真实播放器暂停/Seek 和字幕叠加的像素检查。已检查程序内部生成的 `livekit-app/out/player-standalone/player-subtitles.png`；日志为 `out/player-subtitles-build.log`、`out/player-subtitles-ctest.log`。未操作用户桌面，系统文件选择窗口及实际设备仍未人工验收。

传输专项交接：原生 GoogCC 拥塞原因刷新修复和 MTU 测试修正已保留，原生三组 CTest 通过；C++ SFU 远控完整六组集成通过，见 `out/remote-control/2026-10-27T06-13-31-752Z/evidence.json`。传屏两轮仍未满足原有 30 秒 80 帧门槛，分别解码 58 帧、5 帧，证据 `out/screen-cast/2026-10-27T06-20-03-364Z`、`2026-10-27T06-22-59-881Z`；不将远控通过扩展为传屏稳定性已解决。后续诊断已按用户要求延后。

会议新增房间聊天：支持中文、表情、多行消息，Ctrl+Enter 或按钮发送，显示发送中、已发送及结果未确认状态；断线重连期间禁用发送并保留当前记录，离会/重新入会清空记录。每条最多 2000 字符，保留最近 200 条；接收端校验主题、版本、UTF-8 和发送者身份并去重。发送不自动重试，不包含已读回执、服务端历史、离线消息或私聊。

聊天必要检查：Release 构建通过；单元与无窗口渲染 2/2 已通过，并已查看程序生成的 `livekit-app/out/conference-standalone/conference-chat.png`。联调首次发送曾崩溃，SDK 与会话库统一重建并重新链接后，双向中文多行消息、房间隔离、离会清理和重复入会通过，证据为 `out/conference-chat/2026-10-27T07-24-57-841760Z/evidence.json`。这一结果支持此前编译产物不一致的判断，但不单独证明崩溃根因。该联调使用隔离的官方 LiveKit，不采集真实设备，不代表自研 SFU 或实际设备人工验收；按用户要求不扩展媒体与性能回归。

## 2026-10-27 已实现增量

- 四个桌面应用使用中文标题和主要交互文案；会议、远控新增中文字库，传屏状态码转换为中文。系统字体路径与 `AV_UI_FONT` 支持共用，保留会议 Retina 字体密度适配。
- 传屏、远控网页将业务失败、网络错误及结束原因显示为中文。远控页面离开时撤权请求路径修正为实际业务前缀。
- 会议加入摄像头选择、入会时默认麦克风选项，会中可添加摄像头/所选显示器共享；发布摄像头和屏幕的同时本地预览。支持音视频轨道静音/恢复、视频停止；设备枚举只在用户点击刷新后执行。
- 会议接入 SDK 重连状态，恢复期间禁用媒体修改并允许离会；每轮重新读取当前参与者与轨道。传屏/远控显式关闭媒体自动重连，保持断线结束一次性业务会话的既有授权语义。
- 播放器暂停定位后异步交付一帧预览，时钟冻结且不输出音频；播放前重新定位，保证预览不消耗后续播放内容。新定位/停止/关闭清除旧预览。补充 MPEG-TS 起始 PTS 之前的关键帧预读，修正非零起始时间文件从头定位无帧的问题。

## 继续完成的范围

### 远控文字输入增量（2026-10-27）

已接通网页文字输入、显式发送、能力协商与宿主确认，支持中文、表情、多行内容；增加 256 字符上限、重复请求拦截、修饰键释放、超时停止及不自动重发。被控端批准文案明确包含文字输入。Web 8/8 单测、SDK 1/1 远控单测、共享协议 fixture、桌面 1/1 渲染检查及 Release 构建通过。

早期集成中的文字发送/回执/隔离/停止场景通过，但完整套件暴露了 C++ SFU 视频停滞和官方服务对照初始心跳超时。后续已修复初始握手：浏览器在信令连接后启动心跳，宿主保留不可由续租延长的 10 秒首次心跳期限，建立控制后仍执行 3 秒失联释放。官方 LiveKit 1.13.10 六组完整集成通过，证据为 `out/remote-control/2026-10-27T05-25-02-866Z/evidence.json`，包括额外延迟 4.5 秒的连接。C++ SFU 纯视频弱网恢复仍在修复，不能用官方通过替代自研服务验证。详细目录、哈希和覆盖边界见 [远控验证记录](remote-control/VALIDATION.md#初始握手修复2026-10-27)。真实 Windows 目标应用文字输入尚未人工验收。
