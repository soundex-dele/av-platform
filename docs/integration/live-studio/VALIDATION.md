## 已发现并修复

- FFmpeg 导入库目标作用域导致桌面链接失败。
- 预览图片未成为可交互控件，导致拖动素材无效。
- 结束场次的心跳响应未携带结束快照，浏览器停留在直播状态。
- SFU 清理失败后没有重试；现将清理任务与撤权一起持久化，并在恢复后继续执行。
- 禁用账号未清理其在其他直播间的连接。
- 统计回调复制 mutable 状态导致码率和帧率一直为零。
- SDK 误用实际输入帧率反复限帧；保留协商上限并按连续时间预算控制帧率。
- 业务 HTTP 阻塞连麦音视频转交；现使用独立有界媒体消费路径。
- 录制编码影响节目合成；现通过独立编码线程和有界队列执行。
- 远端离开后残留画面；现使用取消订阅清理及过期回收。
- 缺失图片引发未转换的 WinRT 异常并终止线程；现转换为可恢复的素材错误，异常回归通过。
- D3D 合成后的节目 alpha 未保持不透明，复用为 PK 图层时可能错误透出底层；已修复 alpha 混合，并通过 GPU 不透明输出回归。
